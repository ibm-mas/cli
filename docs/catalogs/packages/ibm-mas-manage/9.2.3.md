Release Notes
--------------------------------------------------------------------------------
### Bug Fixes and Security Updates
- Fixed typo in configMap (9.2.x) (#4049)
- correct meaweb path to support PBR (Manage 9.2) (#3867)
- add /maximo to svcDefaultUrl for optimizer bind_tasks (#4067)
- Updated conflict list for icd and collaborate (#4082)
- Fixed truststore config map FieldValueTooLong issue (9.2.x) (#4055)
- MASISMIG-77631 : DT498398 Grafana Dashboard metrics displays inaccurate representation of pod memory usage. (#4078)
- readOnlyRootFilesystem changes for non-foundation mode (9.2.x) (#4089)
- Removed failing debug statement when there is no foundation pod (9.2.x) (#4133)
- Support readOnlyRootFilesystem policy compliance for BDI 92 (#4100)
- update base images(maint92xdev) (#4145)
- Addressing FIPS 140-2 related issues (9.2.x) (#4160)
- final operand update for sep IFR (#4164)
