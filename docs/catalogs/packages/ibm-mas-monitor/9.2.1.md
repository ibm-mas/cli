Release Notes
--------------------------------------------------------------------------------
### Bug Fixes and Security Updates
- migration number change to 29 for fixpack 9.2.1 (#1989)
- Implement read only root file system for all the monitor deployments (#1991)
- Add tmp volume mount for sql job (#2005)
- update ws operator volume mount (#2006)
- update LAUNCH_ENPOINT_URL route and add in ui deployment (#2007)
- update coreapi image (#2010)
- add emptyDir for server pod for nginxlogs (#2011)
- add subscription role for applying essential role to coreapi and internalapi (#2018)
- support manualRouteMgmt to disable automatic route creation (#2021)
- fix invalid escape sequence in ciscodnaspacedeployment.py (#2023)
- guard bucket patch condition against empty resources list (#2026)
- update edc images to latest fixes 9.2.24 (#2035)
